# Results v3

Pre-registered in [CRITERIA.md](CRITERIA.md), section v3, before this run. Generated by `python study_v3.py`. Timings: TIMINGS_V3.md.

- **Budget** = proposals evaluated per run: one proposed bit flip for the QUBO annealer, one proposed swap for the swap annealer. Both annealers get the same budgets, 200 n and 2000 n proposals (n = number of items).
- Annealers: 5 runs per instance, seeds instance + 1000 r, r = 0..4 (r = 0 is the v1/v2 seed). *Optimal, mean over seeds* = number of instances solved optimally, averaged over the seeds; *range* = worst and best seed. Wilson 95 % = interval on all runs pooled; runs on the same instance are not independent, so it is narrower than an instance-level interval.
- Greedy + 1-swap local search: greedy, then the first improving swap (chosen items and unchosen items scanned in increasing order) until no swap improves; deterministic. Its proposals column is the mean number of swaps it evaluated.
- Gap = mean shortfall vs the reference optimum, over all runs.

## 3. MILP reference checked against enumeration, n = 20, K = 5

MILP (scipy.optimize.milp, HiGHS): maximise a.x - sum b_ij y_ij, y_ij >= x_i + x_j - 1, y_ij >= 0 for the pairs with b_ij > 0, sum x = K, x binary; relative gap 0.

- Proven optimal: 200/200 instances (100 separable + 100 interacting).
